# Therapy mind maps

A small Streamlit app of original study maps for common therapy ideas: the therapeutic process, CBT, thought traps, ACT, case formulation, anxiety, low mood, emotion, the therapeutic alliance, and a blank session map.

The commercial page at `recursospsicologia.online/therapy-mind-maps` could not be retrieved, and that pack is sold as a download. These maps are newly written summaries of widely published clinical ideas. They are for study and supervision discussion, not a treatment protocol.

## Run

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Each map can be downloaded as SVG, a Markdown outline, or Mermaid.
